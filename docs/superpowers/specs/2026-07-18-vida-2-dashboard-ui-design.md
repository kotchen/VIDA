# VIDA 2.0 Dashboard UI 设计文档

- 日期：2026-07-18
- 状态：已获用户批准
- 设计依据：用户提供的高保真设计图（深色铜金"汽水"风格 Dashboard）
- 关联文档：[VIDA 2.0 后端 API 契约](../../api/v2-api-contract.md)

## 1. 背景与目标

VIDA 1.x 是"AI Video Transcriber"：FastAPI 后端 + 原生 HTML/JS 单页前端（`static/`），
单页流程（粘贴 URL / 上传文件 → 转录 → 总结）。

2.0 目标：按设计图把产品升级为**多视图工作台**形态。本设计文档只覆盖第一阶段：
**高保真实现 Dashboard 主视图**，并搭好后续视图（Transcribe / Library / Summaries / Settings）
所需的路由骨架与设计系统。

本阶段**不接真实后端**：使用 Mock 数据 + 类型化数据访问层，视觉还原度是唯一验收重点。
数据契约另行沉淀为独立 API 文档，供后端改造方（另一个 AI）实现。

### 已确认的关键决策

| 决策点 | 结论 |
|---|---|
| 交付形式 | 前端框架重构（非静态原型、非旧前端改造） |
| 技术栈 | React + TypeScript + Vite + Tailwind CSS + shadcn/ui |
| 本阶段范围 | 仅 Dashboard 主视图；其余 4 个导航项为占位页 |
| 数据 | Mock 数据 + TS 数据模型 + Provider 数据访问层 |
| 素材 | AI 生成"汽水飞溅"风格图片（琥珀铜金、气泡感，非咖啡） |
| 实现策略 | 设计系统先行（令牌化）+ 桌面端高保真 |
| 用户系统 | **不做**。无 User 模型、无问候语/头像/通知铃铛/Pro Plan 卡片 |

### 关键效果

- 主按钮 / 徽标：`linear-gradient(135deg, #905020 → #D09050)` 铜金渐变
- Logo：金色渐变文字 + 气泡装饰（SVG/CSS 实现）
- 卡片：暖棕细描边 + 深棕底 + 极轻内发光；**无玻璃拟态**
- Transcript 当前行：铜色高亮背景

### 字体

- Logo / 展示：`DM Serif Display`（设计图 VIDA 为粗衬线金字）
- UI 正文 / 标题：`Manrope`
- 时间戳 / 数字：`font-variant-numeric: tabular-nums`

### 形状与尺寸

- 卡片圆角 16px；按钮 12px；徽章全圆角
- 面板间距 16px；页面内边距 24px
- 侧栏宽 280px；顶栏高 56px

### 组件清单

**layout/**
- `AppShell`：侧栏 + 顶栏 + 内容区的整体框架
- `Sidebar`：VIDA Logo（衬线金字 + 气泡装饰）、5 个导航项、底部汽水飞溅图 + 标语

**dashboard/**（7 个面板）

3. `SummaryCard`：标题 "AI Summary ✨" + "Generated by VIDA" 徽章；摘要正文；底部 3 指标（Read time / Key points / Confidence）
4. `TranscriptCard`：标题 + 搜索框 + 筛选/排序图标；可滚动分段列表（铜色时间戳 + 说话人名 + 正文；首行为当前行高亮）
5. `ChaptersCard`：标题 "Chapters & Highlights" + "Add Chapter" 按钮；章节列表（缩略图、时间戳、标题、时长、书签图标、更多菜单）
6. `RecentProjectsCard`：标题 + "View all"；4 张项目卡横排（封面、标题、日期 · 时长、状态徽章、更多菜单）
7. `ExportCard`：标题 "Export" + 说明文案；3 个大图标按钮（TXT .txt / SRT .srt / MD .md）；底部 "+ More formats coming soon"

**shadcn/ui 基础件**：button、card、badge、input、scroll-area、dropdown-menu、tooltip、separator
**图标**：统一 `lucide-react`

## 5. 数据模型与 Mock 层

`data/types.ts` 是前后端契约的唯一源头（与 API 契约文档保持一致）：

```ts
interface Episode {
  id: string
  title: string
  sourceType: 'upload' | 'url'
  mediaUrl: string
  posterUrl: string
  durationSec: number
  resolution?: string
  status: 'completed' | 'processing' | 'failed'
  language: string
  createdAt: string            // ISO 8601
}

interface TranscriptSegment { id: string; startSec: number; endSec: number; speaker: string; text: string }
interface Chapter  { id: string; startSec: number; title: string; durationSec: number; thumbnailUrl: string; bookmarked: boolean }
interface Summary  { episodeId: string; content: string; readTimeMin: number; keyPoints: number; confidence: number; generatedBy: string }
interface Project  { id: string; title: string; createdAt: string; durationSec: number; status: Episode['status']; thumbnailUrl: string }

interface DashboardData {
  currentEpisode: Episode
  summary: Summary
  transcript: TranscriptSegment[]
  chapters: Chapter[]
  recentProjects: Project[]
}
```

**Provider 层**（`data/provider.ts`）：

```ts
interface DataProvider {
  getDashboard(): Promise<DashboardData>
}
```

本阶段唯一实现为 `MockProvider`（返回 `data/mock.ts` 中按设计图内容编写的示例数据：
"AI Podcast Episode 12"、6 段双人对话、6 个章节、4 个最近项目）。
将来接后端时新增 `HttpProvider`（实现见 API 契约文档），组件代码零改动。

## 8. 错误处理与边界

- Mock 数据即完整数据，本阶段无加载失败路径；`MockProvider` 保持 async 签名，为将来 HTTP 切换保留 loading 状态位（面板骨架屏可后置到接线阶段）
- 窄于 1280px：显示"建议在桌面端访问 VIDA 2.0"的兜底页
- 占位路由：可点击切换，页面显示对应图标 + "Coming in VIDA 2.x"
- 播放器为静态展示（封面 + 播放条 UI），本阶段不实现真实播放

## 9. 测试与验收

- **测试**：Vitest + Testing Library
  - `MockProvider.getDashboard()` 返回数据符合 DashboardData 结构（字段完整性）
  - 组件冒烟：Sidebar（5 个导航项渲染）、TranscriptCard（分段列表渲染）、PlayerCard（标题与元信息渲染）
- **构建验收**：`npm run build` 零 TS 错误；`npm run dev` 可正常预览（端口 7100）
- **视觉验收**：1440×900 视口下与设计图逐项比对：色板、字体、7 面板布局与间距、铜金渐变、圆角、滚动区
- **功能验收**：`/` 重定向到 `/dashboard`；4 个占位路由可切换；侧栏激活态正确

## 10. 明确不做（YAGNI）

- 用户系统（注册/登录/头像/通知/Pro Plan）
- 真实视频播放、真实上传、真实导出
- 移动端适配
- 其余 4 个视图的实际内容
- 后端改动（由 API 契约文档交接）
